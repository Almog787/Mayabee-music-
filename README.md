# Mayabee 🎵

Mayabee is an interactive web-based music creation application that lets you generate dynamic music beats and jam out on an interactive 8-pad grid. Choose your vibe, pick an emotion, and start making music instantly!

🔗 **Live Demo:** [https://almog787.github.io/Mayabee-music-/](https://almog787.github.io/Mayabee-music-/)

## ✨ Features

* **Interactive Music Pads:** 8 distinct tracks containing drums, bass, chords, and melodies.
* **Vibe & Emotion Selection:** Customize your track's feel by picking a genre (Pop, Electronic, Hip Hop) and an emotion (Happy, Sad, Tense, Chill).
* **Auto-Mixer:** A built-in dynamic mixing engine that balances volume levels automatically so your mix stays clean.
* **Live Audio Effects:** Use the XY-Pads to tweak Filter & Delay, or Bitcrush & Reverb in real-time.
* **Record & Download:** Record your live jamming session and download the result directly as an audio file.
* **Bilingual UI:** Full UI and layout support for both English and Hebrew (RTL).

## 🚀 Local Development

Want to run the project on your own machine?

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   *The app will be available at `http://localhost:3000`*

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Tailwind CSS
* **Audio Engine:** Tone.js
* **Build Tool:** Vite
